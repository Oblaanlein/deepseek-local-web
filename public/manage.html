说明
  • 删除单条：点该行的「删除」，会连同只被它引用的附件一起删掉（和官方前端逻辑一致）。
  • 删除全部：清空 IndexedDB 里的对话与附件，不会删除 API Key。操作不可撤销，建议先「导出全部为 JSON」备份。
  • 导入聊天记录：请回到 聊天页面 → 设置 → 「导入历史对话」，支持 DeepSeek 网页版导出的 ZIP；导入会覆盖当前全部本地对话。
  • 官方前端本身也有删除：侧边栏对话的「…」菜单可删除单条，设置里有「删除所有对话」。本页是同一份数据的管理入口，适合批量清理或前端打不开时使用。
  • 注意：如果聊天页面还开着，浏览器会占用数据库，删除可能被阻塞 —— 请先关掉聊天页标签再操作。
