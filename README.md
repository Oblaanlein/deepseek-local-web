# DeepSeek 本地版 · 网页端

在本地跑 DeepSeek 官方 chat-demo 前端，用自己的 API Key 直连官方接口。
官方前端的能力**一个不少**，另外补了官方没有的**花费显示**、**轮次侧栏**和**按轮删除**。

> 非官方项目，与深度求索无关。API Key 和聊天记录**只存在你自己的电脑上**。

---

## 这个仓库解决什么问题

DeepSeek 开源了 chat-demo 前端，但只提供在线演示：本地要跑起来，得自己搞到构建产物、起静态服务、注入 Key。
这个仓库把这些补齐了，并且**在完全不改官方 bundle 的前提下**，用一层注入脚本补上官方没有的能力。

`public/` 是官方 CDN 构建产物的镜像（含全部异步 chunk），所以"网页版的使用体验"是原样保留的；
所有增强都在 `overlay.js` / `sidebar.js` 里，通过 `preload.js` 在页面加载后注入，读写的是官方同一份 IndexedDB。

## 功能

### 官方能力：全部保留

| 分类 | 能力 |
|---|---|
| 对话 | 流式输出、停止生成、重新生成、编辑提问产生分支 |
| 推理 | 深度思考（耗时显示、可折叠） |
| 联网 | 智能搜索、引用来源卡片、链接阅读 |
| 多模态 | 图片/文件上传、朗读、语音输入 |
| 渲染 | Markdown、代码块高亮、表格、引用、Mermaid |
| 数据 | 导入官方 ZIP 备份、导出 |
| 外观 | 明暗主题、中英双语 |

### 官方没有、这里新增的

**1. 每条回答显示花费**

回答下方显示 `tokens · ¥金额`。单价按官方价目表（缓存命中 / 未命中 / 输出**分项计价**），
并且实现了**峰谷价**：UTC 01–04、06–10 之外是低谷，单价减半；周末全天低谷。
悬停看完整明细（命中多少 token、未命中多少、输出多少、按哪个单价算的、美元折人民币）。

**2. 轮次导航侧栏**

把当前对话的每一轮列出来，带**分支计数**（`‹2/3›` 这种），点一下跳到那一轮。
长对话翻历史不用一直滚。

**3. 按轮删除**

多选 / 全选，从上下文里移除指定的问答轮，并把链表重新接上——其它轮和分支不受影响。
官方只能整条对话删，删单轮做不到。

**4. 会话置顶 / 多选删除**

置顶的对话固定在最上方（原位置隐藏）；右上角小图标进入选择态，顶部「选择对话 ✕」、
圆形勾选、底部「置顶 | 删除」操作条，交互照官方 App。

**5. 历史管理页 `/manage`**

官方界面打不开时的兜底：列表、单条删除、清空全部、导出 JSON 备份、清除本地 Key。

## 快速开始

```bash
# 1. 配置（复制模板，填你自己的 Key）
cp config.example.json config.local.json

# 2. 启动
node server.mjs
# 或双击 start.cmd
```

打开：

- 聊天：<http://127.0.0.1:5180/>
- 历史管理：<http://127.0.0.1:5180/manage>

服务只监听 `127.0.0.1`，局域网内其它设备访问不到。端口在 `config.local.json` 里改。

### 填 API Key

**方式 A（推荐）**：写进 `config.local.json`

```json
{ "apiKey": "sk-你自己的key", "forceApiKey": false }
```

- `forceApiKey: false`：只在浏览器还没有 Key 时注入，页面里改过的 Key 会一直生效
- `forceApiKey: true`：每次加载都用文件覆盖

**方式 B**：在页面设置里手填，存在 `localStorage`。

> ⚠️ `config.local.json` 已在 `.gitignore` 里。**不要把它提交到公开仓库**，也不要整个目录打包发给别人。

### 导入官方聊天记录

1. DeepSeek 网页版 → 设置 → 导出全部对话 → 得到一个 **ZIP**
2. 本地页面 → 设置 → 导入历史对话 → 选那个 ZIP

注意官方语义：**导入是覆盖，不是合并**。本地已有对话请先用 `/manage` 导出 JSON 备份。

## 目录结构

```
public/
  index.html          官方构建产物入口
  static/             官方 JS/CSS chunk
  preload.js          注入入口（把下面两个脚本挂到页面上）
  overlay.js          增强层：轮次侧栏、按轮删除、花费显示
  sidebar.js          增强层：会话置顶、多选删除
  manage.html         历史管理页
server.mjs            零依赖静态服务 + Key 注入
config.example.json   配置模板（不含 Key）
```

## 实现要点

- **不改 bundle**：官方产物是压缩过的单文件，直接改会破坏 source map 和后续升级。
  所以增强全部走运行时注入，用 MutationObserver 监听官方渲染出的 DOM 再挂自己的节点。
- **共用一份数据**：增强层读写官方同一个 IndexedDB（库名 `chat-demo`），不另存副本，
  所以官方界面和自己加的侧栏看到的历史永远一致。
- **按轮删除**：官方数据是消息树（`parent_id`），删一轮不是删两条消息，
  而是摘掉该轮及其子树、再把下一轮接回上一轮的父节点，否则上下文会断。
- **峰谷价**：官方价目表是高峰价，低谷（UTC 01–04、06–10 之外）减半，周末全天低谷。
  单价和汇率都写在 `config.local.json` 的 `pricing` 里，调价时改配置即可，不用改代码。

## 隐私

- API Key：存在 `config.local.json`（本地文件）和浏览器 `localStorage`
- 聊天记录：存在浏览器 `IndexedDB`
- 请求路径：页面**直连** `https://api.deepseek.com`，不经过任何中间服务器
- 本仓库不含任何 Key、不含任何聊天记录
